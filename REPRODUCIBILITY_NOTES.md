# Reproducibility Notes

This file records discrepancies observed between the supplied manuscript, the supplied training implementation, and the supplied training-log excerpt.

## 1. Split implementation

The manuscript describes a strict patient-wise split using unique `lesion_id` metadata and reports 6,009 training, 2,003 validation, and 2,003 test samples.

The supplied code, however, constructs:

```python
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
for fold, (_, val_idx) in enumerate(skf.split(df, df.label)):
    df.loc[val_idx, "fold"] = fold
```

This is stratification by image rows, not grouping by patient/lesion. The repository preserves the supplied implementation rather than silently changing the experiment.

**Action before public reproducibility claim:** implement and release the exact patient/lesion-wise split indices used for the manuscript, then rerun the reported experiment if necessary.

## 2. Parameter count

The manuscript reports 124.3M parameters. The supplied training log reports:

```text
✓ Parameters: 137.0M
```

**Action:** determine the exact code revision/configuration that produced the manuscript's 124.3M figure and publish the corresponding checkpoint/model summary.

## 3. Effective batch size

The supplied code configures `batch_size=8` and `grad_accum=4`, implying an effective batch size of 32. The manuscript reports an effective batch size of 16.

**Action:** align the code and manuscript with the actual run.

## 4. Focal-loss gamma

The code header says focal loss `gamma=2`, while the active configuration defines:

```python
focal_gamma = 1.5
```

**Action:** identify the configuration used for the reported manuscript results.

## 5. Training log coverage

The supplied markdown log excerpt contains epochs 1–21 of a 45-epoch run. It does not contain the full 45-epoch run or the final post-hoc calibration output.

**Action:** publish the complete training log and final evaluation artifacts if the full run is intended as the reproducibility record.

## 6. Split-index availability

The manuscript states that patient-wise split indices were publicly provided. No split-index file was present among the uploaded materials used to create this repository.

**Action:** add the exact split manifest once available, without including personally identifying information.

## 7. Baseline comparability

The manuscript explicitly states that the baseline models in the SOTA tables were not all retrained under identical conditions and that those comparisons are indicative.

The repository therefore does not claim that the reported SOTA table is a controlled reproduction of every baseline.

## 8. Clinical interpretation

The manuscript describes the uncertainty triage as a retrospective test-fold simulation and states that prospective multi-centre validation and diverse skin-phototype evaluation are required before clinical deployment.

## 9. Why these notes are included

These discrepancies are not silently "fixed" in this GitHub package because doing so would create a new experimental configuration and could incorrectly imply that the reported manuscript numbers were generated by the modified code. The package is intended to be an auditable starting point for the authors' final reproducibility release.
